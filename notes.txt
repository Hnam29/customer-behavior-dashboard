Thay đổi	                                  Lệnh
app.py hoặc core/*.py hoặc pipeline/*.py	  docker compose restart dashboard
pipeline/*.py (logic Airflow/email)	          docker compose restart airflow-scheduler airflow-dag-processor airflow-apiserver
Cả hai	                                      docker compose restart dashboard airflow-scheduler airflow-dag-processor airflow-apiserver
